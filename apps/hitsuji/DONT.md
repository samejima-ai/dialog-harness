# Hitsuji — スコープ外定義

明示的に「**作らない**」と決めたもの。ここに書かれた領域は SPEC.md に混入してはならない。
AI 能力の向上 / ユーザー要望の変化に伴い、本リストは更新可能。

---

## 1. プラットフォーム

- **iOS 版**は作らない（Android 一択）
- **デスクトップ常駐版（Windows / macOS / Linux）**は作らない
- **Web ブラウザ拡張版**は作らない
- **Wear OS / スマートウォッチ専用版**は MVP には含めない（将来視野）

## 2. 物理世界・モノ系の物忘れ防止

- **「鍵をどこに置いた？」「財布忘れた」のような物理物の位置追跡**は作らない
- **NFC タグ / Bluetooth ビーコン連携**は作らない
- **家電 IoT 連携（"お湯沸かしてるの忘れた" の検知）**は作らない

## 3. 注意散漫系（d 系）

- **SNS 使用時間の検知 / 制限**は作らない
- **アプリ使用状況に基づく "そろそろ別のことしたら？" 通知**は作らない
- **ブラウザタブ数の監視**は作らない
- **作業時間オーバー検知（IoT 不要のものも）**は MVP には含めない

## 4. 認証・認可・マルチユーザー

- **ログイン機能 / アカウント作成**は Phase 1 では作らない（ローカル単一ユーザー前提）
- **家族・友人とのタスク共有**は作らない
- **権限分離（管理者 / 一般ユーザー）**は作らない
- **SNS ログイン連携**は作らない（OAuth は Google Calendar 連携でのみ将来検討）

## 5. ゲーミフィケーション過剰機能

- **他ユーザーとのランキング / SNS 共有機能**は作らない
- **課金 / アイテム購入 / 広告**は作らない（自分専用）
- **ペナルティ・減点・連続日数喪失通知**は作らない（叱責は逆効果）
- **キャラ育成 / アバターカスタマイズ**は MVP には含めない（Forest 系の方向には行かない）

## 6. UX 上の禁止挙動（ユーザー Must "b" より）

- **広告表示**は一切しない
- **不要な確認ダイアログの連打**は作らない（無駄な操作は嫌い）
- **画面遷移を 3 階層以上深くする**設計は避ける
- **同期通信で UI をブロックする実装**は禁止
- **無断でクラウド送信する処理**は禁止（プライバシー保護）

## 7. AI 自律開発困難な領域（dialog-harness 既定 DONT）

- **創造的 UX デザイン**（既存パターン踏襲、奇抜な独自 UI は作らない）
- **高度なパフォーマンス最適化**（Android 標準ライブラリの範疇に留める）
- **未知の外部 API 統合**（OAuth フローの新規実装等は要・人間レビュー）

## 8. データ管理上の境界

- **Phase 1 ではクラウド同期を実装しない**（明示的な Phase 2 移行が必要）
- **データのエクスポート / インポート機能**は MVP には含めない（将来追加）
- **複数端末でのリアルタイム同期**は作らない（Phase 2 でも eventual consistency で十分）
