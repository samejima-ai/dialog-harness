# ケロぴの森 🐸🌿

中学生の妹さんが「ケロぴの相棒」となり、住人の困り事を絵で答えて助ける学習ゲーム。

> 学習者ではなく救助者。絵が描けたら理解できている証拠。

## 主な特徴

- 🎨 **絵で答える**: 描画キャンバスに描いた絵を AI（Gemini マルチモーダル）が概念照合
- 🐸 **ケロぴが主役**: 妹さんがオープニングで描いた絵が本キャラとして以降の世界に登場（Phase 1.1）
- 🌿 **どうぶつの森ライク**: ゆるい時間軸、住人との関係性、図鑑＋絵巻のコレクション
- 📊 **家族で運用**: Google Sheets で問題を追加・編集（コード触らず家族分担可）
- ⏳ **待ち時間も楽しい**: 判定中はミニゲームや解説アニメ。「むしろこっち目当て」OK 設計
