# sensors/inferential.md — 推論的センサー（M2）

計算では検出しきれない、**意図 / 体験 / 哲学**レベルの整合性を検証する観点。
Layer 1 自走中に AI 自身が定期的に問い直す内部チェックポイント。

共通スタックは `../../layer1-autonomous-dev/references/inferential-sensor-v2.md`（Shift Left 基盤 + 5 層エラー検出）参照。本ファイルはプロジェクト固有の追加観点。

## 第 0 層: 大原則（コミット前必読）

| # | チェック | 検出方法 |
|---|---|---|
