# ケロぴの森

中学生の妹さんが「ケロぴの相棒」となり、住人の困り事を**絵で答えて**助ける学習ゲーム。

> 学習者ではなく救助者。絵が描けたら理解できている証拠。

## アプリの全体像（30 秒で把握）

```
[オープニング] 「世界はまだ真っ白…ケロぴを描いて、森の始まりに」
       ↓ 妹さんが描く（最初の絵 = 本ゲームのケロぴ）
[森ホーム] 緑のミニマル景観。ケロぴが画面中央
       ↓ ケロぴが「依頼」をくれる
[依頼受領] 「池の蓮、3/4 だけ緑にしたいの！」
       ↓ 描画キャンバスへ
[描画] スタイラスで描く（線太さ補正、Undo、消しゴム）
       ↓ 「できた！」
[判定] Gemini マルチモーダルが概念照合（実時間 3-10 秒）
       ↓ 待ち時間にミニゲーム or 解説アニメ
[リアクション] 🌟 大喜び / 💭 寄り添い / 🌱 別角度
       ↓ 妹さんの絵が「絵巻」、ケロぴが「図鑑」に追加
[森ホーム] 次の依頼へ（任意のタイミングで終了可）
```

## 開発フェーズ

| Phase | スコープ | 完了目安 |
|---|---|---|
| **1.0 MVP** | 仮素材で全コアループ動作（図形・分数 2-3 問パック） | L1 で完遂 |
| **1.1 キャラ確定** | 妹さんがオープニングで描いた絵を本キャラとして取込 | 妹さん巻込みフェーズ |
| **1.2 ビジュアル強化** | 背景・効果・季節感（β）追加。反応見ながら調整 | Phase 1.1 後 |
| **1.x 単元拡張** | 量グラフ → マイナス → 文章題 順 | 段階的 |
| **2.0** | 国 / 英 / 理 / 社 へ拡張 | Phase 1 安定後（別 SPEC） |
