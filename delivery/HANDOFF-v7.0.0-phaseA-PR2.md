## 1. できたもの

- ルール（罠・RL・叡智の節）を「失効した」と宣言できる欄が規格に載った（`status` / `revoked_at` / `superseded_by`）
- 失効を宣言したのに AI がまだ読み込む位置に残っているルールを、機械が列挙するようになった（判定はしない）
- 振り返り儀式で「失効済み N 件が残っています。退避しますか？」と 1 問聞くようになった
- 退避先（COLD）への移送条件に「失効したものは次のサイクルで」が加わった。従来は「廃止から 2 年」だけだった
- 根拠: 古い記憶を消せないエージェントは、記憶がないエージェントより成績が悪いという実測（失効できれば大きく改善）

## 2. 動作確認方法

```
python3 harness-verifier/verify.py --strict
python3 scripts/test-norm-scan.py
python3 scripts/norm-scan.py | head -8
```

`norm-scan` の出力に「失効済みで購読に残る規範: 0 件」が出れば配線済み（まだ失効させたルールが無いので 0 件）。
